# Thumbnail Prompter

채널 장르·전략에 맞는 Midjourney 프롬프트 2~3개(A/B 테스트용 변주 포함)와 구도·색감·타이포 가이드를 만든다. 이미지 생성은 사용자가 직접 — 본 스킬은 프롬프트 텍스트만 산출.

## 1. 언제 사용하는가

- Mode B Step B5 — 전략 승인 직후 썸네일 자산 생성

## 2. Midjourney 프롬프트 문법 (v6/v7 기준)

기본 구조:

```
<subject> <action/state>, <environment/setting>, <style modifiers>, <lighting>, <composition>, <color palette>, <medium>, --ar 16:9 --v 7 [--style raw] [--stylize <0-1000>] [--no <items>]
```

### 주요 파라미터
| 파라미터 | 용도 |
|---------|------|
| `--ar 16:9` | 유튜브 썸네일 비율 (필수) |
| `--v 7` | 최신 모델 (또는 `--v 6.1`) |
| `--style raw` | 기본 스타일라이즈 약화 — 사실적·차분한 결과에 유리 |
| `--stylize 100` (낮음) ~ `750` (기본) ~ `1000` (높음) | 미술적 해석 강도 |
| `--no <token>` | 부정 프롬프트 (예: `--no text, watermark, people`) |
| `--seed <int>` | 변주 일관성 유지 (시드 고정 후 프롬프트 변경) |

### 구문 모범
- 단어를 콤마로 구분, 핵심부터 → 보조 수식 순.
- 이모지·숫자·특수기호 최소.
- 텍스트(자막) 강제는 **불안정** → 가능하면 텍스트는 사후 편집(CapCut)으로 추가.

## 3. 장르별 시각 코드

### 3.1 sleep-music

**핵심 코드**:
- 인물 없음 (`--no people, faces`)
- 단일 정적 장면 (인테리어·풍경)
- 저채도 + 따뜻한 톤 (저녁·밤·황혼)
- 텍스트는 후편집으로 (자체 프롬프트에 강제 X)

**모티프 후보**:
- Celtic: 안개 낀 숲, 고대 유적, 켈틱 매듭 패턴, 달빛 호수, 폐허된 성탑, 하프
- 자연음: 비 내리는 창문, 모닥불 캐빈, 대양 절벽, 산속 오두막 창가
- 명상: 미니멀 풍경, 단일 촛불, 고요한 호수면, 별이 빛나는 밤하늘

**프롬프트 예시 베이스**:
```
A misty Celtic forest at dawn, ancient moss-covered standing stones, soft golden light filtering through pine branches, painterly fantasy art, muted earth tones, atmospheric haze, peaceful and serene, cinematic composition --ar 16:9 --v 7 --style raw --no people, text, watermark
```

### 3.2 playlist

**핵심 코드**:
- 분위기·시간대 단일 톤 (저녁 카페, 새벽 도로, 비 오는 도시)
- 인물 실루엣 가능 (얼굴 디테일 회피로 저작권·일관성 안전)
- 그래픽·미니멀 일러스트 톤 우선 (사진형은 보조)
- 일관된 시리즈 팔레트 (시즌·계절감)

**프롬프트 예시 베이스**:
```
Lone silhouette by a rain-streaked cafe window, neon signage glow outside, lo-fi illustration style, deep teal and amber palette, intimate composition, melancholy mood --ar 16:9 --v 7 --no faces, text
```

### 3.3 narration (역사·정보형)

**핵심 코드**:
- 시대감 있는 단일 인물·유물·풍경 (단, 실제 인물의 실명 초상 사용 신중)
- 드라마틱 라이팅 (chiaroscuro, 강한 명암 대비)
- 클릭 유도 시각적 hook 1개 (화살표·하이라이트는 후편집으로)

**프롬프트 예시 베이스**:
```
A weathered medieval manuscript opened on a wooden table, candlelight flickering, dust motes in the air, dramatic chiaroscuro lighting, baroque painting style, deep amber and shadow, mystery atmosphere --ar 16:9 --v 7 --style raw --no modern objects, text
```

## 4. A/B 변주 전략

같은 영상에 대해 **2~3개 프롬프트**를 만든다. 변주는 한 번에 1개 차원만 변경 (인과 식별 가능하게).

| 변주 차원 | 예 |
|----------|----|
| 팔레트 | 황혼 톤 vs 청록 톤 |
| 주제(subject) | 풍경 단독 vs 풍경+오브젝트 |
| 무드 | 평온 vs 신비 |
| 시간대 | 새벽 vs 한밤 |
| 시점/구도 | 광각 풍경 vs 클로즈업 디테일 |

권장: **A = 벤치마크 패턴 충실 / B = 1개 차원 변주 / C(선택) = 매니아 화이트스페이스 키워드 노림**.

## 5. 구도·텍스트 가이드 (이미지 생성 후 CapCut 편집)

- **3분할 법칙**: 핵심 피사체를 좌 1/3 또는 우 1/3.
- **텍스트 영역**: 하단 1/3 또는 우상단 코너 — Midjourney에 텍스트 강제하지 않고 후편집.
- **텍스트 분량**: 최대 6단어, 글자 크기 썸네일 폭의 8% 이상.
- **타이포**: sleep-music = sans-serif 얇은 두께(예: Inter Light) / playlist = 모노스페이스 또는 sans-serif 미니멀 / narration = serif 두꺼운 두께(예: Bodoni Bold).
- **언어 분리**: 한·영 병기 시 두 버전 별도 산출물 권장 (벤치마크 §2.2 한·영 시각 코드 분리 일치).

## 6. 출력 스키마

호출자에게 다음 형태로 반환.

```yaml
strategy_ref: <strategy 파일 경로>
benchmark_ref: <benchmark 파일 경로> §2.2
genre: <sleep-music | playlist | narration>
prompts:
  - id: A
    prompt: "<프롬프트 본문>"
    rationale: "벤치마크 §2.2 핵심 모티프 충실 — Celtic forest + 저채도"
    variant_axis: baseline
  - id: B
    prompt: "..."
    rationale: "팔레트 변주 (청록 → 황혼)"
    variant_axis: palette
  - id: C            # 선택
    prompt: "..."
    rationale: "매니아 키워드 medieval celtic castle 결합"
    variant_axis: subject
composition_guide:
  rule_of_thirds: <피사체 위치>
  text_zone: <위치>
  typography: <폰트 가이드>
  language_versions: [ko | en | both]

```

## 7. 자기검증 체크리스트

- [ ] 모든 프롬프트에 `--ar 16:9` 포함
- [ ] sleep-music 장르의 경우 `--no people` 또는 명시적 인물 배제
- [ ] 프롬프트별 변주 차원이 1개로 격리됨 (인과 식별 가능)
- [ ] 특정 아티스트·작품 스타일을 직접 호출하지 않음 (예: "in the style of [살아있는 작가명]" 금지)
- [ ] 텍스트는 후편집 권장으로 표기 (Midjourney 강제 X)
- [ ] 한·영 병기 채널 시 언어 버전 처리 명시

## 8. 안티-표절·안티-파생 가드

- 살아있는 아티스트 이름·특정 영화·게임 IP 직접 호출 금지 (스타일 모방 위험).
- 실제 유명 인물의 초상을 픽션 맥락에 사용 금지.
- 타인 채널의 썸네일 구도를 1:1로 복제하지 않는다 — 모티프(예: "코지 캐빈 + 비")는 공유 가능, 정확한 구도·색조합 복제는 금지.
- 의심 시 호출자에게 보고하고 대체 모티프 제안.

## 9. 금지

- 호출자 승인 없이 이미지 자체를 생성·다운로드하지 않는다 (스킬은 텍스트 프롬프트만 산출).
- 프롬프트에 욕설·정치적 메시지·민감 사회 이슈 직접 호출 금지.
- 채널 프로파일의 금기/제외 주제(profile §4)를 위반하는 모티프 채택 금지.
