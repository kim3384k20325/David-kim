# Script Drafter

채널 프로파일의 **대본 깊이** 설정에 따라 산출 범위를 자동 분기하고, 모드별 구조 템플릿·후킹 공식·체크리스트를 제공한다. 본 스킬은 텍스트 자산만 다룬다 — 썸네일은 `thumbnail-prompter` 사용.

## 1. 언제 사용하는가

- Mode B Step B5 — 전략 승인 직후 대본 초안 작성

## 2. 모드 결정

`/channels/<id>/profile.md` §6 의 `대본 깊이` 값을 기준으로 분기한다.

| 모드 | 적용 채널 예 | 산출 범위 |
|------|------------|----------|
| `full-narration` | 나레이션형 역사 | 후킹(0~30s) + 본문(섹션별) + CTA — 완전 스크립트 |
| `minimal` | 수면음악 | 인트로 멘트(영상 내 자막 1~3줄 또는 짧은 음성 가이드) + 설명란 문구 + 태그 세트 |
| `playlist` | 음악 플레이리스트 | 트랙 소개 1~2줄/곡 + 챕터(타임스탬프) 마커 + 인트로/아웃트로 멘트 |

프로파일 값이 명시되지 않으면 호출자에게 질의(추측 금지).

---

## 3. 모드별 구조 템플릿

### 3.1 full-narration

```markdown
# 대본 — <제목>

생성일: YYYY-MM-DD
대상 채널: <id>
참조 전략: <strategy 파일 경로>
참조 벤치마크: <경로> §2.1·§2.5
대본 깊이: full-narration
영상 목표 길이: <분>

---

## 후킹 (0–30초, 음성 기준 80~100단어)
- 1문장 — 청자가 이미 알고 있다고 믿는 사실을 깬다 (반전 / 의문 / 충격적 사실).
- 2문장 — 영상이 무엇을 약속하는지 (구체적, 시간 명시).
- 3문장 — "그럼 시작합니다" 류 신호 → 본문 진입.

## 본문 (섹션 N개)

### 섹션 1 — <소제목>
- 핵심 주장 (1줄)
- 근거·사례 (출처 명기)
- 장면 묘사 (시청자가 그릴 수 있는 이미지로)
- 다음 섹션으로 넘기는 1문장 ("그런데…")

### 섹션 2 — ...

(섹션은 4~7개 권장 / 영상 분당 130~150단어 기준)

## CTA (마지막 30초)
- 영상 핵심을 1문장으로 재진술
- 구독·다음 영상 예고 1줄
- 정중한 마무리 1줄

## 설명란 (별도)
- 1줄 후킹 (검색 스니펫용)
- 영상 챕터 (타임스탬프)
- 출처·참고 자료 링크
- 해시태그 5–10개
```

#### 후킹 공식 (full-narration)
- **반전형**: "다들 X라고 알고 있지만, 사실은 …"
- **의문형**: "왜 X는 …했을까?"
- **충격적 사실형**: "1592년 …에서 …이 일어났다."
- **시간 약속형**: "이 영상 4분이면 …의 진짜 이유를 알 수 있다."

저작권 보호 콘텐츠(타 영상의 후킹 그대로) 차용 금지 — 패턴만 참조.

### 3.2 minimal

```markdown
# 대본 자산 — <제목>

생성일: YYYY-MM-DD
대상 채널: <id>
참조 전략: <경로>
참조 벤치마크: <경로> §2.5·§2.6
참조 키워드: <경로>
대본 깊이: minimal

---

## 1. 인트로 (영상 내 자막 1~3줄, 0~10초)
- 자막 1: 환경/분위기 묘사 (한 줄, 명사구 중심)
- 자막 2: 용도 키워드 1~2개 (예: "Sleep · Meditation")
- 자막 3 (선택): 채널/시리즈 명

자막은 **음성 없음** 권장 (수면 장르 — 음량 변화 최소화).

## 2. 설명란 (검색 스니펫용)

### 첫 100자 (스니펫에 노출)
- 1문장 분위기 묘사 (한국어 또는 영어)

### 본문
- 분위기 묘사 단락 (2~3문장)
- 용도 클러스터 키워드 나열 (벤치마크 §2.5 패턴)
- 챕터/트랙 마커 (있으면)
- 외부 링크 (Bandcamp / Spotify / 작곡가 사이트 — 호출 채널이 보유한 경우만)
- 면책: "All audio composed/generated by <channel>. No copyrighted material used."

## 3. 태그·해시태그 세트

벤치마크 §2.6 패턴 + 키워드 §3 우선 추천에서 도출.

### 해시태그 (5~10개, 영상 설명 상단 또는 제목 직후)
- #<...>
- ...

### 일반 태그 (15~25개, YouTube Studio 태그 필드)
- ...

## 4. 제목 후보 2개 (A/B)

A: <전략 §제목 안 1>
B: <전략 §제목 안 2 또는 변주>

각 제목이 어떤 키워드/시장을 노리는지 1줄 설명.
```

#### minimal 모드 체크리스트
- [ ] 인트로 자막에 자극적 표현·급격한 색상 변화 유도 단어 없음
- [ ] 설명란 첫 100자에 검색 키워드 1개 이상 자연스럽게 포함
- [ ] 한·영 병기 채널이면 설명란 단락을 두 언어로 (또는 토글 형식)
- [ ] 외부 링크는 채널 자체 자산만 — 타인 곡·이미지 링크 금지

### 3.3 playlist

```markdown
# 대본 자산 — <제목>

생성일: YYYY-MM-DD
대상 채널: <id>
참조 전략: <경로>
대본 깊이: playlist

---

## 1. 인트로 멘트 (자막 또는 짧은 음성, 0~15초)
- 1줄 분위기 + 1줄 추천 시청 상황 (예: "Late-night drive" / "비 오는 카페")

## 2. 트랙 소개 (곡당 1~2줄)

| # | 시작 | 곡 (또는 분위기 명사구) | 한 줄 소개 |
|---|------|------------------------|------------|
| 01 | 00:00 | <분위기 명사구 — 곡명 직접 차용 금지> | ... |
| 02 | 03:42 | ... | ... |

곡명·아티스트명을 직접 적시하는 대신 **분위기 명사구**(예: "Misty Harbor at Dawn")로 표기한다 (저작권 안전).

## 3. 챕터 마커 (설명란용)
```
00:00 - <01 분위기>
03:42 - <02 분위기>
...
```

## 4. 아웃트로 멘트 (0~10초)
- 1줄 마무리 + 채널 다음 플레이리스트 안내

## 5. 설명란 + 태그
- minimal 모드 §2~§3 형식 재사용
- 추가: "Tracks selected/composed by <channel>. License: <self-composed | royalty-free + 출처>"
```

#### playlist 모드 체크리스트
- [ ] 곡명·아티스트명 직접 표기 없음 (분위기 명사구 사용)
- [ ] 라이선스 출처가 모두 명시됨 (자작 또는 사용 권한 보유)
- [ ] 챕터 시작 시각이 정확히 0:00 시작
- [ ] 다음 플레이리스트로의 자연스러운 연결 (시리즈성)

---

## 4. 공통 안티-표절 가드

전 모드 공통 — 산출 전 자기검증.

- [ ] 특정 작품·영상의 문장을 **직접 복사**하지 않았다 (≥7어 연속 일치 금지)
- [ ] 인용·차용은 출처 명시
- [ ] 곡명·작품명·인물명을 픽션 전개의 핵심 소재로 사용하지 않는다 (역사 다큐 제외)
- [ ] 후킹·CTA 문구가 특정 인기 영상의 시그니처와 동일하지 않다
- [ ] 음악 자산은 채널이 직접 생성/소유한 것만 ([Suno](https://suno.com) 자작 등)

위반 의심 시 즉시 멈추고 호출자에게 보고 (대체 표현 제안).

## 5. 전략 인용 의무

산출물 첫 3줄 이내에 다음을 명시한다.
- 참조 전략 파일 경로 (어떤 전략을 실행하는 대본인가)
- 참조 벤치마크 파일 경로 (어떤 패턴에 정렬했는가)
- 참조 키워드 파일 경로 (어떤 키워드를 노리는가)

본문 내에서도 전략·벤치마크·키워드 번호(예: 벤치마크 §2.1 / 키워드 §3 추천 #2)를 인용한다.

## 6. 금지

- 곡 가사·소설 본문·타 영상 내레이션 직접 복사 금지.
- 의료·법률·금융 단정적 조언 금지.
- 자극적 단어로 클릭베이트 강화 (특히 수면 장르) 금지 — 채널 신뢰도 훼손.
- 호출자 승인 없이 전략·프로파일을 수정하지 않는다.
