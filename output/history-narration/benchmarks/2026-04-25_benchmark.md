## 2. 패턴 추출 (6개 차원)

### 2.1 제목 공식
- 공통 패턴: **인물명·왕명 + 충격적 사실/의문 어구** 결합. "왜", "진짜", "숨겨진", "TOP", 숫자 패턴(N년·N대) 빈출. 한·영 혼용은 거의 없음(순수 한국어).
- 근거 사례: 검색 결과 인용 — "5000년동안 한반도를 지켜낸 레전드 장군 TOP3" (국경없는 수다 EP.94, 채널 인근 권역) / "이순신 장군의 죽음, 자살인가 암살인가? | 426년 만에 공개된 기록…" (검색 1위 노출 영상) — 두 사례 모두 **숫자(연도/순위) + 미스터리 의문 어구** 공식.
- 호출 채널 1호 영상 ("세종대왕은 왜 한여름 빗속에서 거적을 깔고 울었나") 이미 이 공식 위에 있음 — CTR 16.7%로 검증됨.

### 2.2 썸네일 요소
- 공통 패턴 없음 — **데이터 갭** (WebFetch 차단으로 썸네일 이미지 직접 확인 불가).
- 큐레이션 기사 인용으로 확인 가능한 일반 패턴 1건: 디디행성·교양만두 류는 "친근한 일러스트·캐릭터" / 황현필·썬킴 류는 "인물 사진 + 큰 한글 타이포". → 호출 채널 사진+타이포 스타일이 후자 클러스터에 정렬.

### 2.3 영상 길이
- 공통 패턴 없음 — **데이터 갭**. 단, 외부 인용으로 확인된 분포: 강의형(썬킴·황현필)은 **15~60분 장편**, 교양 단편형(교양만두 등)은 **10~15분**. 호출 채널의 5~15분 운영은 후자 군집과 정렬.
- 근거 사례: 디디행성·도도도 류 큐레이션 기사 — "10분 만에 알아보는 역사" 슬로건 인용.

### 2.4 업로드 시간대
- 공통 패턴: **주 1회 정기 슬롯 운영** (이탈 방지). 교양만두 = "매주 목요일 19시" 명시 (나무위키 인용).
- 근거 사례: 교양만두 — 주 1회 목요일 19시 정기 업로드.
- 다른 두 채널의 업로드 슬롯은 **데이터 갭**.

### 2.5 설명란 구조
- 공통 패턴 없음 — **데이터 갭** (WebFetch 차단으로 설명란 첫 100자 확인 불가).
- 일반화: 한국 교양·역사 채널은 첫 1~2줄 후킹 + 출처 인용 + SNS·강의 CTA가 표준. 호출 채널 운영 시 채택 권장.

### 2.6 태그·해시태그
- 공통 패턴 없음 — **데이터 갭** (페이지 패칭 차단). 일반 추정으로 #한국사 #조선시대 #역사 #썰 등이 빈출이라는 큐레이션 기사 인용은 있으나, 실제 태그 노출 위치는 미확인.

## 3. 호출 채널에 적용 가능한 시사점 (3~4개)

| # | 시사점 | 레버 라벨 |
|---|--------|----------|
| 1 | **제목 공식 — "인물/왕명 + 의문 어구 + 숫자/연도"** 를 표준 템플릿으로 명문화. 호출 채널 1호 영상이 이미 이 공식으로 CTR 16.7% 달성 → 후속 영상도 동일 공식 유지. 클릭베이트성 과장 형용사("충격" 단독, "역대급") 는 금기 정합 위해 회피. | CTR 레버 |
| 2 | **영상 길이 5~12분으로 고정** (교양 단편형 군집 정렬). 평균시청 1:36(2.1%)이 매우 낮은 호출 채널 현실에서, 장편 강의형(썬킴·황현필 군집, 15~60분) 모방은 유지율 추가 악화 위험. 짧은 길이로 절대 평균시청시간 회복부터. | 유지율 레버 |
| 3 | **주 1회 정기 슬롯** (예: 매주 X요일 Y시) 도입. 교양만두 사례처럼 슬롯 고정이 재방문·구독전환의 누적 신호. 슬롯 결정은 시청자 활동 시간대(B2 도달범위·시청자 탭) 데이터 1회 수집 후 확정. | 양쪽 (CTR 노출 균질화 + 유지율의 상위 지표인 채널 충성도) |
| 4 | **첫 30초 "반전·의문" 후킹 표준화** + 1:00 / 3:00 지점에 미니 후킹(추가 의문/예고). 평균시청 2.1%는 도입부 이탈 가능성 매우 높음 — 도입 30초·1분·3분 3단 후킹 골격 도입을 다음 사이클 script-drafter 호출 시 강제. | 유지율 레버 |

## 4. 데이터 갭 / 한계

- WebFetch 차단(403)으로 채널별 1차 메타(정확 구독자, 총 영상 수, 최근 영상 제목·조회수·길이, 썸네일 이미지, 설명란 첫 100자, 태그) **대부분 미확보**.
- 구독자 수치는 외부 인용(나무위키·뉴스) 1회성 시점만 — 실시간 추정 아님.
- 조선 단일 시대 전문 채널은 본 사이클에서 발굴 못함 — 다음 갱신 사이클 시드 키워드를 "조선왕조실록 + 단편", "조선 미스터리 사건" 등으로 좁혀 재시도 필요.
- 황현필 한국사는 정치 진영 언급 사례가 일부 보고되어, 패턴 인용 시 정치 색채가 묻은 영상은 제외 필요(호출 채널 §4 금기 정합).
- 영상별 정확 조회수는 어느 채널도 검증되지 않음 — 본 리포트는 패턴 일반론 위주, 영상별 정량 비교는 의도적 회피.
