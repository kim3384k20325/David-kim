## 5. 데이터 갭 / 한계

- **한국어 "켈틱 + X" 결합 키워드의 경쟁강도 표본 부재**. 6개 키워드가 `?`. 한국어 시장에서 명시적으로 "켈틱"을 채널 정체성으로 가져가는 10K~1M 채널을 검색만으로 확정하지 못함 (벤치마크 §4 한국 시장 갭과 동일 원인). → 첫 한국어 업로드 후 자체 노출 데이터로 라벨 보강 필요.
- **검색량·CPC 미확보**. 본 보고서는 라벨(상/중/하/?) + 1줄 근거만 제공 (스킬 §9 / 호출 규칙). 정량 비교가 필요한 경우 별도 API 통합 필요.
- **YouTube 자동완성 직접 관찰 불가** (검색 도구는 결과 페이지만 반환). 자동완성 1순위 가산점은 본 라벨링에 미반영 — 실제 운영자가 YouTube 검색창에서 시드 입력 후 보강 가능.
- **Sleepy Piano(§부록 A 채널 4) 영상 메타 미확보** 상태로 한국어 우선 추천 7~8번의 정확한 경쟁 압력 측정 불가. Mode A 갱신 시 보강.
